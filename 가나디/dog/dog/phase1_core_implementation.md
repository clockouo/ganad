## 목표와 1차 범위

강아지가 침대에서 시작해 주인을 깨우고, 집 앞길의 강한 빛을 피한 뒤 목줄에 묶인 공원 철문을 열고 공원 입구까지 진행한다. 퍼즐 01과 02는 상호작용을 익히는 짧은 게임으로 첫 만남 회상과 연결하지 않는다. 퍼즐 03에서 목줄과 회상이 함께 처음으로 이야기를 전달한다.

## 01 집

1. 강아지가 침대 가까이에서 침대를 클릭한다. Map01의 침대 없는 배경 위에 분리된 침대 프레임과 이불 레이어를 놓는다. 클릭 직후 별도 근접 화면이 중앙에서 원형으로 0.48초 동안 퍼져 열린다. 침대 위 주인이 없는 원본 사진은 수연님이 수정해 제공한다. 얼굴 리듬 원과 진행 점 네 개를 보여준다. 줄어드는 원이 겹치는 타이밍에 네 번 성공하면 이불이 반응하고 주인이 깬다. 조기 입력·시간 초과 시 같은 원이 다시 나타나며 성공 진행은 유지한다. 하단 안내 문장은 표시하지 않는다.
2. 처음에는 집을 살짝 어둡게 둔다. 주인이 일어나 벽 스위치까지 걸어가 눌러 불을 켠 뒤 화장실로 들어간다.
3. 플레이어는 자유롭게 주인 쪽으로 이동한다. 바닥의 공을 지나가며 건드릴 수 있지만 공을 굴리는 행위나 위치는 진행 조건이 아니다.
4. 화장실에 들어간 뒤 4초가 지나면 주인이 자동으로 나와 현관으로 향한다. 복도 위치와 공 접촉은 조건이 아니다.
5. 주인은 현관 경첩에서 왼쪽 1유닛 지점에 선다. 강아지는 쓰다듬는 손 앞의 목표 위치까지 자동으로 접근한 뒤 고정된다. 어느 쪽에서 접근했든 주인을 바라보며, 주인은 클릭 대기 전부터 쓰다듬는 자세를 취한다. 카메라는 집의 고정 높이와 가로 경계를 유지하고 크기 2.65로 당긴다. 강아지 위의 클릭 아이콘이 나타난 뒤 화면 아무 곳이나 클릭하면 퍼즐 02를 시작한다. 자동 접근은 4.5초 안에 종료한다.
6. 퍼즐 02는 1018 PPT 13–14쪽처럼 흐릿한 강아지 정면 이미지가 가로 쓰다듬기에 따라 선명해지는 별도 uGUI 근접 화면이다. 첨부된 선명한 이미지 원본을 `Assets/Resources/Puzzle02/PettingPortrait.png`로 사용하며 원본은 보관하고 강아지 투명 레이어·배경·독립된 UI 화살표로 분리해 표시한다. 열린 순간의 집 화면을 흐리게 깔고 중앙에 원본 비율의 카드(1280×720 기준 폭 608)를 보여준다. 카드 안에서 왼쪽 버튼을 누른 채 가로로 문질러야 진행된다. 누적 수평 거리 ÷ (카드 표시 폭 × 1.6)이 진행률이며 왕복·여러 번 나눠 문지르기를 허용한다. 시작 클릭·제자리 클릭·세로 이동·카드 밖 이동·대기는 진행시키지 않는다. 블러 반경은 원본 픽셀 기준 10→0으로 연속 감소하며 25/50/75/100%에서 네 점이 채워진다. 완전히 선명해진 이미지는 Point 필터로 0.65초 보여준 뒤 닫고 주인 퇴장으로 이어진다. 방 전체의 색 덮개를 지우는 동작은 제거한다. 하단 설명 자막·회상은 넣지 않는다. 뒤쪽 월드 카메라는 크기 1.9, 높이 플레이어 Y+1.1의 집 경계 안에서 잠근다.

## 02 집 앞길

1. 외부 화면 시작 직후 주인이 화면 오른쪽 가장자리 근처에 나타나 약 2초 걸은 뒤 사라지는 동안 카메라와 강아지를 고정한다. 장면이 끝나면 카메라 추적과 자유 조작을 복구한다. 외부 카메라 배율은 집 안과 같게 유지해 강아지의 상대 크기를 맞춘다. 강아지는 직접 입력하기 전까지 제자리에 머문다.
2. 강아지는 A/D 직접 입력으로 주인 방향으로 움직인다. 차 전조등의 강한 빛 경계에는 들어갈 수 없고, 다가가면 자동으로 뒤로 물러난다. 불이 켜진 동안 진입할 때마다 뒤로 물러나며 머리 위 느낌표를 다시 띄운다. 이번 차량 조우는 튜토리얼용이며 후퇴 뒤 약 2.5초에 불이 꺼진다.
3. 공원 입구 철문이 목줄로 묶여 있다. 가까이서 철문을 클릭하면 손잡이까지 직접 걸어가 입이 닿은 뒤 목줄을 문다. A/D로 실제로 뒤로 0.45유닛 당기면 목줄 근접 화면이 열린다. 제자리 클릭이나 앞으로 이동만으로는 열리지 않는다. 목줄이 풀린 뒤 코로 문에 닿아 밀면 왼쪽 문짝만 열린다.

차량은 02 원본 그림을 사용한다. 램프 중심은 X≈14.324, 바닥 Y+0.800이고 좌우 시작점은 약 ±0.750유닛이다. 로컬 빔은 길이 2.05·시작 반폭 0.20·끝 반폭 1.90·바깥 이동 0.40이고 루트 X 배율은 약 0.4839, Y 배율은 0.45로 줄여 표시와 판정을 함께 맞춘다. 별도 차량 렌더러는 비활성화한다.

### v2.33 원본 배경과 상호작용 표시

침대 기상 전(WakeTheOwner), 강아지가 바닥에 서서 조작 가능한 상태이고 PlayerInteraction의 현재 대상이 상호작용 가능한 침대일 때 강아지 위에 왼쪽 마우스 클릭 표시를 띄운다. 실제 클릭과 같은 탐색 범위·방향 조건을 사용한다. 범위를 벗어나거나 침대를 등지면 숨기며, 근접 퍼즐 진입과 기상 이후에도 숨긴다. 쓰다듬기 시작 전과 같은 크림색 마우스 아이콘·어두운 받침·점멸을 사용하고 별도 키나 하단 자막은 추가하지 않는다.

`자료/02_.png`를 바이트 변경 없이 `Assets/Art/AfterTheGlow/References/Map02_Original.png`에 원본을 보관하고 플레이용 Sprite는 상단 제목 띠를 제외해 사용한다. 집 앞길부터 공원 입구까지 X=6.6–24.6, 폭 18유닛으로 배치한다. 원본의 집·차·자전거·기둥·나무·가로등·색·비율을 유지한다. 제목은 원본에 보존되지만 일반 플레이 카메라의 위쪽 밖에 있다. 집 앞 외부 시작점은 원본 현관 위치 X≈8.465, 주인 시작점은 그 오른쪽 0.8유닛이다.

철문 중심은 X≈21.024이며 움직이는 문짝은 원본 기둥 안쪽에 맞춘다. 왼쪽 문짝만 밀기에 반응한다. 별도 기둥 그림은 끈다. 공원 내부 Map03은 X=24.6–42.6에 같은 폭·픽셀 배율로 이어 붙이고 도로 경계 높이를 맞춘다. 현재 배경은 ExteriorStitch로 하늘·도로 경계를 연결한다. 수연님의 후속 연결 원화는 아트 교체 작업으로 별도 관리한다. 물리 바닥과 카메라 오른쪽 경계도 X=42.6까지 확장한다. 공원 진입 지점은 X=25.14이다.

철문 개방 뒤 공원 진입은 직접 이동이다. 집 안 쓰다듬기 위치 자동 접근의 기존 4.5초 제한만 유지한다.

쓰다듬기 시작 대기에는 강아지 위의 클릭 표시를 어두운 받침 위에 선명하게 표시한다. 근접 카드 안에서는 Canvas 위의 독립된 표시로 왼쪽 마우스 버튼과 좌우 화살표를 보여주고, 버튼 점멸·작은 좌우 움직임을 준다. 블러 배경 뒤에 가려지지 않고 진행 점과도 겹치지 않는다. 하단 설명 문장은 넣지 않는다.

## 퍼즐 03 — 목줄과 첫 만남

원본 회상 이미지 8개를 보존하고 파손용 철망 배경·투명한 목줄 양 끝·손을 거둔 회상 이미지를 추가한다. 하단 설명 자막은 넣지 않는다. 회상은 총 네 번의 클릭으로 진행하고 각 회상 뒤 현재의 약해진 목줄로 자동 복귀한다.

## v2.45 실내 조명

- 기존에는 기상 직후 욕실 Light2D만 활성화했다. 집 배경과 캐릭터는 Unlit 재질이어서 실내 밝기가 바뀌지 않았다. HomeRoomLighting의 집 범위 전용 어두운 레이어로 실제 화면 변화를 연결한다.
