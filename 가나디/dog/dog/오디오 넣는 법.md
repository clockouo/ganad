# 상황별 오디오 연결하기

Unity 메뉴에서 **Tools → After the Glow → Audio Connections**를 엽니다. 설정 창에는 현재 게임에서 소리를 재생하도록 연결된 상황들이 배경 음악·환경음과 효과음으로 나뉘어 표시됩니다.

각 상황의 오디오 칸에 Project 창의 AudioClip을 끌어 놓거나, **가져오기**를 눌러 컴퓨터의 `.wav`, `.mp3`, `.ogg`, `.aiff` 파일을 선택하세요. 가져온 파일은 `Assets/Resources/Audio/UserAdded`에 복사되면서 해당 상황에 바로 연결됩니다. 변경은 자동 저장됩니다.

Play 모드에서 창의 **재생** 버튼으로 연결한 클립을 들어볼 수 있습니다. 실제 장면에서 나는 시점을 확인하려면 Play 모드로 게임을 진행하세요. 전체·배경·효과음 크기는 게임 설정 메뉴에서 조절할 수 있습니다.

비워 둔 상황은 같은 키 이름의 오디오 파일이 `Assets/Resources/Audio`에 있으면 그 파일을 사용합니다. 창에서 직접 연결한 클립은 파일 이름과 관계없이 우선 사용됩니다.

새로운 종류의 장면 상황은 이 창에 나타나지 않습니다. 그 상황에서 재생 이벤트를 코드에 한 번 연결한 다음, 오디오 연결 창에도 항목을 추가해야 합니다. 현재 연결된 상황은 다음과 같습니다.

| 상황 | 오디오 연결 창의 이름 |
| --- | --- |
| 배경 음악 | 전체 장면 배경 음악 |
| 집 안 환경음 | 집 안 환경음 |
| 공원 환경음 | 공원에 들어왔을 때 환경음 |
| 길 환경음·자동차 공회전 | 길 장면 환경음·길에서 들리는 자동차 공회전 |
| 침대·강아지 냄새 | 침대에서 움직일 때·강아지가 냄새를 맡을 때 |
| 벽 스위치 | 벽 스위치를 켤 때·벽 스위치를 끌 때 |
| 철문 | 철문을 흔들 때·철문 걸쇠가 움직일 때·철문이 열릴 때 |
| 발소리·쓰다듬기·공 | 나무 바닥을 걸을 때·쓰다듬기 퍼즐에서 손을 움직일 때·공이 굴러가기 시작할 때 |
