# 외부 카메라와 퍼즐 줌 조정 방법

> **v2.45 우선 규칙:** 집은 처음에 살짝 어둡고, 기상 후 주인이 기존 벽 스위치까지 걸어가 손으로 누른 뒤 밝아진다. 스위치 소리·버튼 변화·밝기 전환을 같은 순간에 시작하고 이후 화장실로 들어간다. 정원 안쪽 문 열림·중앙 목줄·분수대 기억 순서와 기존 승인 사항은 유지한다.

> 기준: Unity 6000.6.2f1 · SampleScene · 버전 2.33 · 2026-10-21

v2.33은 카메라 크기 3과 강아지 배율 1.5를 유지하면서 외부 배경 자체를 45%로 축소한다. 카메라 크기를 바꾸는 것만으로 배경과 강아지 사이의 비율이 바뀌지는 않는다. 외부 관련 표시·충돌·진입 좌표는 같은 배율로 맞춘다.

v2.29 이전 규칙(기록): 외부 주인 퇴장 관찰 뒤 자동 추적을 사용했고, 공원 내부 탑뷰는 구현 범위에 포함하지 않았다. 이 기록은 v2.33 동작 기준이 아니다.
> 전체 진행 기준은 [1차 구현 핵심](phase1_core_implementation.md)과 [구현 스펙](../../.document_work/2026-10-13-story-revision/After_the_Glow_Implementation_Spec.md)을 따른다.
> 이전 카메라 안내는 [.document_work/2026-10-18-revision/archive-v2.17/camera_adjustment.md](../../.document_work/2026-10-18-revision/archive-v2.17/camera_adjustment.md)에 보존한다.

## Inspector에서 카메라 조정하기

1. Unity에서 Assets/Scenes/SampleScene을 연다.
2. Hierarchy에서 Main Camera를 선택한다.
3. Inspector의 Camera Follow에서 원하는 기본 프레이밍 값을 조정한다.
4. Game 탭과 Scene 탭에서 경계 안에 집 또는 외부 바닥이 모두 보이는지 확인하고 씬을 저장한다.

| Camera Follow 항목 | 용도 |
|---|---|
| Home Orthographic Size | 집 일반 플레이의 화면 높이. 작으면 가까워지고, 크면 더 넓어 보인다. |
| Home Follow Response Multiplier | 기본 1. 실내 완충 시간을 smoothTime과 같게 유지한다. |
| Match Exterior Size To Home | 켜면 집 밖 강아지 배율을 집 안과 맞춘다. |
| Exterior Orthographic Size | 외부 일반 플레이의 화면 높이 |
| Offset | 집에서 카메라가 플레이어를 따라갈 때의 상대 위치 |
| Exterior Offset X | 외부 카메라에서 강아지를 화면 왼쪽/오른쪽 어디에 둘지 |
| Exterior Lock Y / Exterior Locked Y | 외부 카메라 높이를 고정할지와 고정 높이 |
| Home Map Max X / Exterior Map Min X / Map Max X | 카메라가 집·외부 배경 밖을 보지 않도록 하는 경계 |

Orthographic Size는 화면의 반 높이다. 낮출수록 줌인한다. 가로 화면에서는 폭이 Size × 2 × 화면 종횡비로 계산된다. 값을 바꿀 때 맵의 좌우 끝이나 바닥이 화면 밖으로 나가지 않는지 함께 본다.

## 자동으로 실행되는 이야기 카메라

퍼즐 진행 중 Inspector의 기본값과 다른 임시 줌을 쓴다. 사용자 조작과 연출이 끝나면 이전 카메라 위치·크기·추적 상태를 복구한다.

| 장면 | 임시 화면 크기 | 동작 |
|---|---:|---|
| 퍼즐 01 깨우기 | 별도 전체 화면 | 침대 클릭 뒤 근접 화면이 열리고, 얼굴을 네 번 터치할 때까지 플레이어 조작을 잠금 |
| 현관 대기 | 2.65 | 집 고정 높이에서 주인·강아지 사이를 조금 당겨 보여줌 |
| 퍼즐 02 쓰다듬기 | uGUI 카드 + 뒤쪽 월드 1.9 | 1280×720 기준 폭 608, 원본 비율의 정면 강아지 카드. 집 화면을 흐리게 깔고 카드 블러를 10→0으로 줄임. 뒤쪽 카메라는 플레이어 Y+1.1·집 경계 안에서 고정 |
| 퍼즐 03 목줄·회상 | 2.8 | 기억 이미지가 화면 전체를 채움 |

이 값은 일시적인 장면 연출이다. 퍼즐 도중 Inspector에서 기본 카메라 값을 바꾸면 종료 시 이전 저장값으로 돌아간다. 기본값을 바꾸려면 장면 연출이 끝난 상태에서 수정한다.

## 집과 외부를 분리하는 기준

v2.33 배경 기준: 외부 02는 X=6.6–24.6, 공원 03은 X=24.6–42.6이며 각각 폭 18이다. 배경을 기존의 45%로 줄였고 강아지 배율은 바꾸지 않는다. 외부 스폰 X≈8.465, 철문 중심 X≈21.024, 공원 진입 X=25.14, 분수 X=33.6이다. 제목 띠는 플레이용 Sprite에서 제외한다.

집에서는 기존 맵 경계에 맞춰 방을 따라간다. 가로 오프셋 0, SmoothDamp 0.18초와 Home Follow Response Multiplier 1로 강아지의 가로 중앙을 부드럽게 따라간다. 외출 뒤 Exterior Orthographic Size는 Home Orthographic Size와 같게 표시한다. 주인은 카메라 오른쪽 가장자리에서 약 2초 걸어 화면 밖으로 나간다. 열린 현관의 검은 영역에 플레이어가 닿으면 외부로 전환한다.

기본 경계는 Main Camera Inspector에 저장된 현재 값이 기준이다. 카메라를 바꿀 때 배경이나 플레이어 월드 위치를 대신 이동시키지 않는다. 배경·바닥 배치와 카메라 프레이밍을 따로 조정한다.

현재 01–03 구역은 사용자가 준 3:1 지도 일러스트를 가로로 연결한다. 집 배경은 18×6 월드 유닛이며 Home Orthographic Size 3을 유지하면 화면 높이에 맞고, 카메라는 플레이어를 따라 가로로 이동한다. 카메라 좌우 경계가 배경 밖을 보지 않는지 확인하고, 02·03 구역 바닥선도 집 바닥과 이어지는지 확인한다. 04–07 이미지는 다음 구역에 쓸 제목 없는 배경 에셋으로 준비되어 있다.

## 빠른 되돌리기

카메라가 연출 뒤에도 확대되어 있거나 정지해 있으면 씬을 다시 시작해 본다. 재시작 후에도 지속되면 Main Camera에서 Home/Exterior Orthographic Size 및 Camera Follow 활성 상태를 확인하고 SampleScene을 저장된 상태로 복구한다. 외부 프레이밍은 외부 일반 플레이에서만 조정하며 자동 close-up 시에는 값을 바꾸지 않는다.

### v2.34 배경 연결

원본 두 장의 폭 18을 유지하고 도로 행 555/544를 정렬한다. 연결 배경은 36×7.7이며, X=24.6 ±0.65에서 이어 섞는다. 하늘 채움은 높이 64로 늘리지 않고 제목 띠 아래 깨끗한 질감만 화면 여백에 연장한다.

### v2.38 중앙 추적

Offset X와 Exterior Offset X는 0, 실내외 SmoothDamp는 0.18초, Home Follow Response Multiplier는 1이다. 가로 중앙을 추적하되 맵 끝에서는 화면 양끝이 배경 경계를 넘지 않게 제한한다. 매우 넓은 화면에서는 맵 폭에 맞게 기본 크기를 제한한다. 일반 16:9에서는 크기 3이다.
